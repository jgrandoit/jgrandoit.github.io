GTA Clipper Privacy Policy

Last updated: November 16, 2026

What GTA Clipper is

GTA Clipper is a personal, non-commercial tool run by a single creator on their own computer. It is not offered to other users.

Data it accesses

  • YouTube: through the YouTube Data API, with the youtube.upload permission, it uploads videos to the creator's own channel. It does not read, collect, or store any other YouTube data, and it does not access other people's accounts.
  • Twitch: it reads public clip information and public chat activity for channels whose clipping programs the creator has joined, and creates clips on those channels under the creator's own Twitch account.

How data is stored

Sign-in tokens and a list of processed clips are stored only on the creator's own computer. Nothing is sent to any server operated by GTA Clipper; there isn't one. Chat messages are counted in memory to detect busy moments and are not saved.

Sharing

No data is sold, shared, or used for advertising. Data goes only to the platforms it comes from (YouTube, Twitch), and video titles may be generated using the Anthropic API.

Google API Services

GTA Clipper's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. You can revoke access at any time at myaccount.google.com/permissions.
